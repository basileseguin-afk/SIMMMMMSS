Production ORY · page de secours

Le site ne s’est pas chargé jusqu’au bout la dernière fois

Il s’est probablement figé en relisant vos données enregistrées. Vous êtes sur une page de secours, qui ne fait aucun calcul : vos données sont intactes. Récupérez-les, puis repartez sans elles, ou réessayez.

1. Récupérer vos données

Un fichier ory-sauvegarde, le même que « Sauvegarde › Sauvegarde complète » : il se relit ensuite depuis le site (Sauvegarde › Restaurer). Il contient le plan réel de l’unité : ne le publiez pas.

2. Repartir

Mettre de côté ne supprime rien : les données sont gardées dans ce navigateur, et « Remettre » les rétablit.

3. Réessayer sans rien changer

Si le site a été mis à jour depuis, un rechargement complet (Ctrl + Maj + R, ou Cmd + Maj + R sur Mac) prend la dernière version.
